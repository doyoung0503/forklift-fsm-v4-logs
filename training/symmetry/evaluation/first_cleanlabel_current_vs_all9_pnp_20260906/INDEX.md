# Cleanlabel: 현재 PnP / 전체 9점 PnP

[비교 영상](20260903_192254_cleanlabel_current_vs_all9_pnp.mp4)

왼쪽: 실제 FSM PnP 함수 그대로(점수 0.5 필터, RANSAC, inlier LM; 전면 4점 IPPE 폴백 포함).
오른쪽: 0~8번 전체를 동일 가중치로 EPNP + LM. 점수 필터와 RANSAC 이상치 제거 없음.
같은 프레임의 cleanlabel 추론 결과를 양쪽에 동일하게 사용했습니다.

청록색 선은 PnP 재투영 박스, 노란 선은 선택된 전면입니다. 십자와 번호는 모델의 원시 키포인트이며, 초록은 최종 사용점, 빨강은 제외점입니다.
Input IDs는 후보점, Used IDs는 최종 사용점입니다. 실패 프레임은 PnP FAILED로 표시합니다.
아래쪽은 양쪽 동일 영역의 2배 확대입니다. RMS all9는 모든 점에 대한 재투영 오차이며 RMS used는 각 방법이 사용한 점에 대한 오차입니다. 재투영 오차는 실제 3D 정확도의 정답 평가가 아닙니다.

두 방식 모두 동일한 카메라 내부 파라미터와 현재 FSM 치수(1.1 x 0.15 x 1.1 m), 동일한 최대 투영 면적 전면 선택 함수를 사용합니다. 시간 평활화는 없습니다. 원본 744프레임, 17.508 FPS를 유지합니다. 실제 FSM 설정은 변경하지 않았습니다.

프레임별 사용점, 자세, 투영 좌표는 frame_results.json에, 공통 모델 출력은 model_keypoints.npz에 저장했습니다.

## 이번 영상의 실제 결과

- 전체 744프레임 중 모델 검출 691프레임, 미검출 53프레임입니다. 검출 후 PnP 실패는 없습니다. status.json의 failures는 미검출도 포함한 자세 결과 없음 횟수입니다.
- 검출된 키포인트의 최소 점수는 약 0.9525로 모두 0.5를 넘었습니다.
- 현재 방식도 검출된 691프레임 모두 9점을 최종 inlier로 사용했습니다.
- 따라서 두 방식의 결과는 수치 오차 수준에서 같습니다. 최대 yaw 차이 약 1.09e-7도, 최대 중심 좌표 차이 약 7.57e-10m입니다.
- 원본 및 비교 영상의 전체 프레임 디코딩 검증에 오류나 경고가 없습니다.
- 이는 이 영상에서 점 선택 차이가 없었다는 뜻이지, 모든 영상에서 두 방식이 동등하거나 실제 3D 자세가 정확하다는 뜻은 아닙니다.
