# FSM v4 내부 벽을 포함한 삽입 승인

2026-09-08 사용자 제공 치수: 팔레트 1.10 × 1.10 m, 지지 블록 0.20 × 0.20 m, 구멍 폭 0.25 m, 포크 한 개 폭 0.115 m. 두 포크 바깥 간격은 기존 설정 0.60 m를 사용한다.

전면 중심을 (u=0, d=0), 내부 방향을 +d로 두면:

- 블록 가로 구간: [-0.55, -0.35], [-0.10, 0.10], [0.35, 0.55] m
- 블록 깊이 구간: [0, 0.20], [0.45, 0.65], [0.90, 1.10] m
- 위 구간의 조합인 9개 블록이 존재한다. 2행과 4행은 비어 있다. 전면은 5행이다.
- 좌우 입구: [-0.35, -0.10], [0.10, 0.35] m
- 카메라 기준 좌우 포크 가로 구간: [-0.30, -0.185], [0.185, 0.30] m (현재 포크 중심 X=0 기준)

## 승인 계산

`calib/fsm_v4/insertion_geometry.py`의 `check_insertion_sweep()`가 공통 판정이다. 팔레트 좌표의 블록 꼭짓점 (u,d)을 현재 차량 좌표로 바꾼다.

```
vehicle_x = pallet_x + cos(yaw) * u + sin(yaw) * d
vehicle_z = pallet_z - sin(yaw) * u + cos(yaw) * d
```

1. 각 포크의 안쪽/바깥쪽 경계가 자기 쪽 전면 구멍에 들어오는지 확인한다. 현재 포크 끝이 전면을 이미 넘은 상태는 승인하지 않는다.
2. 각 벽을 팔레트 가로·깊이 방향으로 1 cm 확장한다. `INSERT_WALL_MARGIN_M`으로 조정하며, 접촉도 거절한다.
3. 승인 예정 이동 거리 `pallet_z - INSERT_CAMERA_Z_REMAINDER_M`만큼 전진할 때 각 포크가 지나가는 전체 영역과 9개 확장 블록의 교차를 분리축 검사(SAT)로 계산한다. 프레임/거리 간격 샘플링이 아니므로 샘플 사이의 벽 관통을 놓치지 않는다.
4. 전진 시 포크는 일정 폭을 가진 스트립으로 취급하며, 뒤쪽은 모든 블록보다 뒤까지 보수적으로 연장한다. 실제 포크 길이를 임의로 추정하지 않는다.
5. 기하 검사와 기존 yaw 제한을 모두 통과한 경우에만 승인한다. 후보 회전 후 예상 자세에도 같은 기하를 적용하며, 실제 정지 관측 후 `_accept_insertion()`에서 다시 확인한다. 안전 후보가 없으면 FAILED/STOP 처리한다.

`fork_opening_alignment()` 함수명과 반환형은 호출부 호환성을 위해 유지하지만 의미는 앞면 검사에서 전체 계획 삽입 구간 검사로 변경되었다. 반환 hits는 기존처럼 전면 외측 교차 위치이다. 구형 `INSERT_OPENING_SPAN_M=0.70`은 표시/기존 시뮬레이터 호환값이며 단독 승인 기준이 아니다.

## 예와 검증 범위

정렬된 상태에서 각 포크는 바깥벽과 5 cm, 중앙벽과 8.5 cm 떨어진다. X=0, Z=1.8 m, yaw=-5°는 구형 외측선 기준을 통과하지만 새 기준에서는 오른쪽 포크와 3행 5열 블록 간섭으로 거절된다.

삽입 실행은 기존 시간 모델을 유지한다. 예를 들어 Z=1.8 m이면 1.5 m를 명령하며, 정렬 상태에서 카메라-포크 끝 거리 1.18 m 및 잔여 Z=0.30 m에 따라 포크 끝의 목표 진입 깊이는 0.88 m이다. 팔레트 전체 1.10 m를 관통하도록 이동 목표를 늘린 변경은 아니다. 기하 검사는 해당 목표까지 닿는 블록만 충돌로 판정한다.

1 cm 여유는 추가 기하 여유이며 PnP 오차의 보장 범위가 아니다. 일정 자세의 직진을 가정하고, 수직 간섭·포크 굽힘/뒤꿈치·조향 편차·제동 초과 이동은 모델에 없다. 삽입 중에는 기존처럼 PnP 피드백 없이 시간 모델로 전진하므로 실차 무간섭 보장을 뜻하지 않는다. 기존 시뮬레이터의 연속 개구부/분리 포켓 충돌 표시 모델은 이번 9개 블록 모델과 별개이며 실차 검증 대신 사용하지 않는다.

검증: 삽입 관련 오프라인 테스트 50개 통과(회귀 사례, 중앙벽, 후면벽, 여유 경계, 누락 치수, 직접 승인 우회, 회전 후 재확인, 시간 제어). 전체 depth_cam 테스트 156개 중 153개 통과, torch 미설치에 따른 import 오류 3개. 하드웨어 실행 없음.
