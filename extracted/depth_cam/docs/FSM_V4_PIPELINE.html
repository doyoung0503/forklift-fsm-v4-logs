실패 시 동작

--calibrate 실행 중 어느 단계든 실패하면 기존 artifact를 그대로 보존하고 FSM v4를 시작하지 않는다. 기본 빠른 시작은 artifact가 없거나 맞지 않으면 내장 fitted fallback을 사용한다. 실행 중 응답 hot-swap은 하지 않는다.

각도와 회전축

적합 입력은 yaw_deg 열의 heading으로 고정한다. FACE/RECENTER의 bearing 제어에서만 실측 카메라 오프셋 0.68 m와 현재 거리를 이용해 heading 응답을 변환한다.

모든 보정의 공통 주기

회전과 직진은 목적은 다르지만 같은 폐루프 패턴을 따른다.

① STOP이전 동작 종료
② 안정 관측연속 pose 수집
③ 계획짧은 안전 동작 선택
④ 명령ROT / FWD / BACK
⑤ 선제 STOP정지 후 위치 예측
⑥ Settle & 검증관성 종료 후 재측정

⑥의 결과가 목표가 아니면 ②~⑥을 반복한다. 방향을 즉시 반전하거나, 움직이는 중 얻은 한 프레임만으로 다음 큰 동작을 계획하지 않는다.

회전 제어

최대 waypoint 회전은 20°. 새 로그 기반 response가 정지시간·등가속·등속과 “STOP 직전 속도 → 약 2초 뒤 회전량” 관성 회귀로 hold 시간과 coast를 예측한다. 실시간 PnP가 더 빠른 회전을 보이면 일찍 STOP한다.

직진 제어

한 macro-step은 최대 0.8 m, 모델 신뢰 하한은 0.2 m다. 현재 이동량과 제한된 예측 전진량을 더해 목표 통과 전에 STOP하고, 안정화 뒤 실제 이동량을 다시 계산한다.

안전·복구 경로

정상 경로보다 먼저 평가되는 제한들이다. 치명 조건은 항상 STOP 후 FAILED로 모인다.

1
화면 가시성

팔레트 전면 코너가 55° fallback FOV와 8% 화면 여유 안에 남는 회전·직진 조합만 허용한다.

2
시각 손실 유예

연속 PnP 손실 1초 미만은 bounded command만 유지한다. 새 동작은 시작하지 않는다.

3
복구 또는 실패

1초 손실이 확정되면 STOP → RECOVER_VISUAL. 추가 1초 안에 복구되면 ACQUIRE, 아니면 FAILED.

4
동작 예산

회전 시간·방향 변경·standoff 보정·waypoint 횟수·누적 전진거리·전체 pipeline 시간에 상한이 있다.

5
진전과 overtravel

두 waypoint 주기 동안 유효 진전이 없거나 staging 평면을 위험하게 넘으면 FAILED.

6
삽입 interlock

자동 삽입 중 yaw 또는 lateral이 허용 범위를 벗어나면 즉시 STOP 후 FAILED.

공통 실패 처리: 실패한 상태와 이유를 기록하고 STOP을 송신한 뒤 FAILED에 머문다. DONE도 계속 STOP을 유지한다.
