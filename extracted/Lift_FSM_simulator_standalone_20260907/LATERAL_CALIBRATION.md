# 거리별 초기보정 레터럴 기준 실험

현재 적용 기준은 [변경된 로직 재측정 및 FSM 적용 결과](verification/lateral_recalibrated_20260909/README.md)를 따른다.
`L_limit = 0.10 + 0.190 * max(0, min(D, 5.0)-2.26)`을 초기보정 진입에 적용했다.
아래 내용은 회전 타이머/근거리 재계획 변경 전의 **과거 측정 기록**이며 현재 계수가 아니다.

2026-09-09. 실제 차량 설정은 변경하지 않고, 현재 FSM을 별도 프로세스와 가상 CAN으로 실행한다.

## 측정 결과와 후보값

좌우 결과는 아래 정밀도에서 동일했다. 성공/실패 경계는 물리적 한계의 오차 범위나 통계적 신뢰구간이 아니라 **검사한 배치에서의 결과**다.

| D (m) | 안쪽 성공 레터럴 (m) | 인접 실패 레터럴 (m) | 보수적 후보 임계값 (m) |
|---:|---:|---:|---:|
| 3.0 | 0.275000 | 0.281250 | 0.225060 |
| 3.5 | 0.362500 | 0.368750 | 0.309560 |
| 4.0 | 0.475000 | 0.481250 | 0.394060 |
| 4.5 | 0.630938 | 0.636094 | 0.478560 |
| 5.0 | 0.893750 | 0.900000 | 0.563060 |

4.5m는 바깥쪽에 다시 성공하는 구간이 있다. 최초 이진탐색의 0.7125m 성공을 전체 허용범위로 채택하지 않았다.

```python
# 검증 대상 도메인: 3.0 <= D <= 5.0, 단위 m
L_limit = 0.10 + 0.169 * (D - 2.26)
initial_correction_needed = abs(pose.rot_x_pallet_m) > L_limit
```

이 식은 제안이며 실차 FSM에 반영하지 않았다. 초기보정 동작 자체의 실행 가능 조건은 별도로 유지해야 한다.

최종 추가 검증은 **44/44 성공**했다: 선행 정지 제거 조건에서 임계값/중간 거리/절반 레터럴/다른 초기 방향 34회, 기존 선행 정지를 유지한 현재 FSM에서 10회. 기준 탐색과 내부 재검사는 175회였다. 이 결과는 검사한 점들에 대한 성공이며 전체 연속 영역이나 실차 구동오차에 대한 보장은 아니다.

최소제곱 기울기는 0.253525였으나 일부 거리의 측정 경계를 초과하므로 채택하지 않았다. 측정점 하한 기울기 0.211694에 0.8을 곱한 뒤 소수 셋째 자리로 내림해 **0.169**를 선택했다.

## 재현

시뮬레이터 폴더에서:

```powershell
python audit_lateral_motion.py
python calibrate_lateral.py --disable-predictive --output verification/lateral_no_predictive_20260909
python summarize_lateral.py
```

기존 결과가 있으면 같은 좌표의 실행을 캐시에서 읽는다. 소스/시뮬레이터 버전 또는 override가 다르면 별도 출력 폴더를 사용해야 한다. 실제 차량의 `calib/fsm_v4/config.py` 값을 수정하는 명령은 없다.

실험 중 별도 브라우저 작업이 서버와 해시 목록을 갱신했다. 직접 실행 `Session` 소스는 새 해시 목록 항목을 제거하면 원본 바이트 해시와 일치했고, D4/L0.475 재실행의 전체 trace hash도 일치했다. 이 특정 메타데이터 변경만 허용한 근거는 결과 폴더의 `manifest_bridge.json`과 `manifest_bridge_replay.json`에 보존했다.

## 조건

- 거리 D: 팔레트 전면에 수직인 **차량 회전 중심**까지의 거리. 카메라 Z나 직선거리가 아니다.
- 거리 3 / 3.5 / 4 / 4.5 / 5m, 좌우 각각 탐색.
- 차량의 팔레트 좌표 레터럴은 `rot_x_pallet_m`; 거리 D는 `-rot_z_pallet_m`.
- 회전 중심 `(L,0)`, 팔레트 전면 중심 `(0,D)`. 초기 차량 방향은 `atan2(-L,D)`로 팔레트 중심을 바라본다.
- 카메라 높이 0.50m에 해당하는 vertical_offset=0.425m, 가로 FOV 55도, 고정 전면 선택, 포크 한쪽 폭 0.115m.
- 모델/FSM 주기 30Hz. 추가 구동·회전 이득 오차, 인식 잡음·편향·지연·탈락, IMU 오차 모두 0.
- 초기보정 `COARSE_IMU_ENABLED=False`.
- 기준 실험만 `FWD_PREDICTIVE_MAX_ADVANCE_M=0`으로 전진 선행 정지를 제거한다. 삽입 거리 진입, 시야, 정렬, timeout 및 이산 CAN 전송 규칙은 유지한다.
- 실행 성공은 FSM 완료 + 시뮬레이터 접촉 없음 + 삽입 잔여 거리 허용 범위 충족이다. 실행 제한은 기본 185초로 유지한다.

## 최초 결과를 교정한 이유

처음에는 확률적 구동오차만 0으로 두었다. 그러나 FSM은 전진 시 최대 12cm의 추가 이동을 예상해 먼저 STOP하고, 시뮬레이터는 정지 이후 추가 관성 이동을 하지 않았다. D=4m/L=0.55m의 첫 80cm 명령이 실제 68.47cm로 종료됐다.

회전 모델은 관성이 포함된 최종각 회귀식을 사용하므로 추가 관성 차감은 없었다. 상세 코드·CAN 종점 검증과 동일 조건 비교는 [구동 감사](verification/lateral_motion_audit_20260909/README.md)에 기록했다.

## 탐색과 해석

1. 레터럴 0 성공 확인 후 0.1m부터 2배씩 늘려 성공/실패 구간을 찾는다.
2. 이진탐색으로 구간 폭을 1cm 이하로 좁힌다.
3. 경계 안쪽 25/50/75/90%와 바깥쪽을 추가 확인한다.
4. 실패 뒤에 성공이 나타나면 단조성을 가정하지 않는다. 가장 먼저 **관측된** 실패와 그 아래 성공 사이를 다시 이진탐색하고 내부 표본도 재검사한다.

4.5m에서 레터럴 0.7125m는 성공했지만 0.64125m는 실패했다. 따라서 단순 이진탐색으로 얻은 가장 큰 성공 값을 전체 허용 구간으로 사용할 수 없다. 추가 검사는 드문 실패 구간이 전혀 없음을 수학적으로 증명하지는 않는다.

## 기준식

`A = D - 2.26m`, `L_tol=0.10m`로 두고 측정한 안쪽 성공 경계 `B_i`에서:

```text
k_envelope = min_i((B_i - L_tol) / (D_i - 2.26))
k_candidate = floor(0.8 * k_envelope * 1000) / 1000
L_limit(D) = 0.10 + k_candidate * (D - 2.26)
```

보정 가능한 추가 레터럴 성분에 20% 여유를 두는 공학적 선택이다. 실차 오차분포로 추정한 성공 확률은 아니다. 별도 reserve 거리는 0으로 두어 같은 여유를 중복 적용하지 않는다. 적용 범위는 D=3~5m이며 범위 밖 외삽은 검증하지 않는다.

후보 식은 0.25m 간격의 9개 거리에서 양쪽 임계값, 측정 거리에서 절반 레터럴, 일부 다른 초기 방향으로 확인한다. 기존 선행 정지 정책을 유지한 현재 FSM에서도 별도로 후보 임계값을 확인한다. 최종 숫자와 성공 여부는 생성되는 `verification/lateral_no_predictive_20260909/fit.json`을 따른다.

## 산출물과 한계

- `trial_*.json`: 조건, 상태 전환, 성공/실패 사유, 실제 자세, 소스 ID, trace hash.

- `fit.json`, `trials.csv`, `lateral_threshold.png/.svg`: 후보식, 추가 검증 및 그래프.

모델은 실차 관성의 시간 분포나 주행 편차를 새로 식별한 것이 아니다. 이산 제어 주기로 목표를 수 mm 초과하는 현상은 남는다. 시뮬레이터 접촉 검사는 기존 외측 개구부 모델이고, FSM의 삽입 허용 검사는 9개 블록 sweep 모델이므로 서로 같은 검사가 아니다. 판정은 두 조건을 모두 통과하도록 했으나 차량 전체 충돌을 검증한 것은 아니다.
