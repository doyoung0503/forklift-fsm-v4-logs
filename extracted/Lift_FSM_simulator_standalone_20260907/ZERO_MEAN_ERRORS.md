# Zero-mean simulation errors

All new normalized scenarios fix drive_scale=rotation_scale=imu_scale=1 and imu_bias_deg_s=imu_noise_deg_s=0. Retired biased settings in saved presets are ignored after validation. Historical reports are unchanged; replay under this model is intentionally not guaranteed to match old hashes.

Drive and rotation: actual displacement = nominal displacement + nominal displacement * epsilon. A new independent epsilon~N(0,sigma^2) is sampled when the corresponding motion axes change/start; it is held for that segment, not resampled per tick. Default sigma=.1/1.6448536269514722=.0607956831911769. Thus central90% errors are between -10% and+10%, with5% in each tail. This is not MAE10%. No clipping is applied to Gaussian gain; very large user-selected sigma can mathematically yield sign reversal (epsilon<-1).

IMU: one run-constant gain error epsilon ~ N(0, (imu_angle_sd_deg / 90)^2) is sampled using the IMU seed at session creation. Reported unwrapped yaw = initial true yaw + (1 + epsilon) * (true unwrapped yaw - initial true yaw); reported gyro rate = (1 + epsilon) * true rate. The same gain persists across all rotations, reversals and stops in that run. Default sigma5deg means endpoint-error standard deviation5deg for a true90deg rotation (45deg ->2.5deg, 180deg ->10deg), not an exact5deg error on every turn. A95/90 gain gives a smooth95deg reading for a true90deg turn; stopping at measured90deg corresponds to true85.26deg before other dynamics. There is no per-sample jitter or stationary drift. Opposite rotation cancels the corresponding signed accumulated error. A fixed absolute yaw offset alone cancels in relative-turn control, so this model uses calibration gain bias. Across runs the gain error has zero mean; within a run it is systematic. Sigma0 gives ideal observations. Sampled gain and model version are recorded in provenance. Extremely large configured sigma can yield a nonpositive Gaussian gain; no clipping is applied, as with drive/rotation errors.

This replaces the earlier per-sample IMU model on2026-09-09. Existing zero_mean_matrix_20260909 results used independent per-sample5deg jitter and do not validate this new model.

UI exposes only the three standard deviations for these errors. Drive/rotation values are fractions (.0608 means6.08%). Saved explicit standard deviations remain respected; presets with older .188/.05 values must be changed to the new defaults to use90% within10%. Restart server and reload browser/new session to avoid mixed old/new imports.
